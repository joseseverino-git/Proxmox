Comandos Rápidos de Solución en Proxmox VE

Ejecuta estos comandos en la terminal Shell de tu nodo Proxmox VE (como root o con sudo) para garantizar que el usuario y token de monitoreo estén configurados correctamente:

1 Crear el usuario de monitoreo en Proxmox 
pveum user add monitoring@pve --comment "Spotlight Dashboard"
2 Asignar el rol de sólo lectura (PVEAuditor) en la raíz '/' 
pveum acl modify / -user monitoring@pve -role PVEAuditor
El rol PVEAuditor otorga visibilidad total sobre Nodos, VMs, LXCs y Almacenamientos sin conceder permisos de escritura ni alteración.
3 Generar el API Token 'spotlight' (sin separación de privilegios) 
pveum user token add monitoring@pve spotlight --privsep 0
⚠️ Copia el código UUID que Proxmox muestra en la columna value. Pégalo en la ventana de Configuración de este Dashboard.
4 Verificar conectividad por curl desde la terminal 
curl -k -H "Authorization: PVEAPIToken=monitoring@pve!spotlight=TU_TOKEN_UUID" https://192.168.1.100:8006/api2/json/version
5 Verificar el servicio web de la API y Firewall en Proxmox 
systemctl status pveproxy && pve-firewall status
